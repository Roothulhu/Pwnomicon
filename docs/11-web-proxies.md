<summary><h1>📢 Introduction</h1></summary>

Currently, most web applications connect to backend servers to send and receive information. To capture the requests and traffic between web apps and backend servers, and manipulate them, we need to use web proxies.

Web proxies are specialized tools that sit between a browser and a backend server to capture and analyze all web requests sent between both, essentially functioning as a man-in-the-middle (MITM). These tools operate on web ports such as (but not limited to) HTTP/80 and HTTPS/443.

One of their essential uses consists of intercepting a specific request to modify its content and see how the backend server responds to or handles it.

Some tasks for which they can be useful are:

* Web App Vulnerability Scanning
* Web Fuzzing
* Web Crawling
* Web App Mapping
* Web request Analysis
* Web configuration tests
* Code reviews

The most used tools for this are:
BurpSuite and ZAP
